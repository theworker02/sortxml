# sortxml

Sort timestamps and xml durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/sortxml/

## Install / run

```bash
git clone https://github.com/theworker02/sortxml.git
cd sortxml
node src/cli.js
node --test
```
